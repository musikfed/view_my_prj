Как записать и проверить SD-образ
SD CARD EXPORT / T23N

Скачать и записать SD-образ

После завершения сборки нажми «Скачать образ .img» на карточке нужного файла. Никакого одноразового кода, ID или терминала: панель сама выберет образ и сверит SHA256, MBR, MSPL LBA34, FAT16/uImage и ext4 перед передачей. Сборка ядра не повторяется. Кнопка «Проверить SD» остаётся для просмотра схемы.

Доступ: скачивание приватных образов разрешено только клиентам доверенной локальной сети Huananzhi (по умолчанию внутренняя LAN и loopback). Панель всё ещё без входа: любой, кто попал в разрешённую сеть, может скачать образ с персональными Wi-Fi настройками. Не открывай порт 62404 в интернет; для удалённого доступа используй защищённый VPN или SSH.

В Windows открываем скачанный .img в Rufus или balenaEtcher, выбираем именно SD через кардридер и запускаем запись. Предварительное форматирование не нужно. Файл является образом целого диска: MSPL уже расположен на LBA34, повторный seek=34 запрещён.

После записи — безопасное извлечение и проверка загрузки на T23N. Не форматируй предложенный Windows раздел ext4.

Исходники и проверка конвейера

ЛИНИЯ 03 / WIFCAM HELPER · INGENIC T23N · SD

WifCam Helper · прошивка камеры-ассистента

Отдельная SD-прошивка T23N: камера — глаза, микрофон — уши, динамик — голос; CV/STT/LLM/TTS работают на CORE. Два зафиксированных Git SHA и отдельный каталог образов.

↗ GitHub Helper
Один проект · Получить Git → собрать собственную SD-прошивку → проверить IMG → скачать → испытать микрофон, динамик, видео на камере
▣ Дерево прошивки Helper—Только T23N / MIPS / FAT16 / ext4
GITHUB HELPER + WIFICAM BASE → HUANANZHI → SD

Два независимых источника, одна проверенная сборка

Основной проект musikfed/wifcam_helper / main содержит собственную rootfs-надстройку для камеры. Зафиксированная база: musikfed/wificam_T23N / mymarrchWFcam. В сборке автоматически сохраняются оба Git SHA, базовый WIFICAM не заменяется.

Один реальный SD-образ, а не копия обычной WIFICAM или запуск Python-стенда. После записи через Rufus нужны физические тесты RTSP, SC2336, микрофона и динамика; наличие кода не гарантирует аппаратную работу.
