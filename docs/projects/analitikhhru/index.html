SOURCE-BASED PRESENTATION

Что внутри

Market Radar — локальная программа для агрегированной аналитики вакансий и резюме. В основе — браузерный сбор и SQLite, а не публичное API-соединение со страницы GitHub Pages.

Здесь показаны STOCK и FLOW, HR-плотность, сценарии K и исторический proxy. Открытые вакансии рекрутеров не означают число уже работающих специалистов.

Векторные обложки воспроизведены по присланным снимкам, а исходная вёрстка приложения показана выше.
