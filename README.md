# VIEW_MY_PRJ — PegiNelab Project Gallery

A **separate public showcase** of the original user interfaces and verified technical presentations of the projects developed under `musikfed`.

- Each public project has its **own standalone project page**. No generic identical boxes or fictional UI screenshots.
- Source-based previews use existing screenshots, artwork and real frontend assets. A static preview does **not** run a Python/Rust backend or control real hardware.
- Private projects stay in their private repositories; do not expose their source code, names, or internal configuration in the public site without separate approval.
- Eleven languages are for showcase pages and descriptions; application UI locale support is documented per project.
- Project-specific GitHub Pages sites are maintained by each project's own repository and settings. The gallery is a directory, not a replacement for those sites.
- Runtime modifications, backends, secrets and deployment systems are **outside this gallery's scope**.

**Publishing:** GitHub repository Settings → Pages → Deploy from branch → `main` / `docs`. Then open `https://musikfed.github.io/view_my_prj/`.
